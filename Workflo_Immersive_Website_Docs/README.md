# Workflo Immersive Website Documentation

This package is specifically for the **Workflo public website**.

It keeps the Workflo product motive constant:

> A privacy-first autonomous QA agent that runs software in isolated
> sandboxes and produces verifiable test receipts.

## Design references

### Primary reference

The supplied Workflo launch-page image remains the main visual
direction:

-   dark futuristic launch page,
-   acid-lime accent,
-   premium 3D object,
-   dense product UI,
-   engineered typography,
-   cinematic sections.

### Interaction reference

Anime.js is used as the interaction/animation reference for:

-   scroll-linked timelines,
-   smooth/eased scroll synchronization,
-   text splitting,
-   staggered motion,
-   timeline orchestration,
-   Three.js animation integration.

The website should take the **interaction principles** from Anime.js
rather than copy its visual identity.

## Files

-   `PRD.md` --- website goals, target users, page narrative, section
    requirements, interactions, conversion and launch criteria.
-   `design.md` --- visual system, 3D art direction, scroll
    choreography, typography, buttons, motion, responsive behavior and
    design tokens.
-   `Tech.md` --- production website stack, Anime.js + Three.js/R3F
    architecture, Next.js structure, performance, accessibility, SEO,
    testing and deployment.

## Core narrative

`CODE → ISOLATE → GENERATE → VALIDATE → EVIDENCE → RECEIPT → VERIFY`

## Scope boundary

This is a website specification, not a backend product architecture. The
public site may demonstrate Workflo concepts using controlled frontend
demos but must not claim synthetic execution is real.
